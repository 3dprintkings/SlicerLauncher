# Privacy

## SlicerLauncher 1.0.0 source snapshot

SlicerLauncher is designed to work locally on the user's Windows computer.

### Data stored locally

SlicerLauncher stores its settings under the current user's AppData profile. Depending on the features used, this can include:

- configured slicer names
- paths to configured slicer executables
- the selected default slicer
- automatic-launch settings
- paths to recently opened STL or 3MF files

This information is used locally by SlicerLauncher and is not intentionally uploaded by the application.

### Network communication

SlicerLauncher does not perform an automatic update check and does not contact a 3dprintkings or GitHub update endpoint.

The application itself does not upload model files, configured slicer paths, recent-file paths, analytics events, advertising identifiers, or telemetry.

The About window contains a user-initiated link to the 3dprintkings website. If the user chooses that link, the website is opened in the default browser and the browser's and website's own privacy behaviour applies.

Official binary application updates are intended to be distributed through the Microsoft Store.

### Analytics, advertising, and tracking

SlicerLauncher does not contain:

- analytics SDKs
- advertising SDKs
- behavioural tracking
- usage telemetry
- user accounts
- cloud storage of model files

### Third-party applications

When a user chooses a slicer, SlicerLauncher starts the executable configured for that third-party application and passes the selected model-file path to it. From that point onward, the third-party application's own privacy practices apply.
