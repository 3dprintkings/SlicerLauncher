# Privacy

## SlicerLauncher 1.1.0

SlicerLauncher is designed to work locally on the user's Windows computer.

### Data stored locally

SlicerLauncher stores settings under the current user's AppData profile. Depending on the features used, this can include:

- configured Slicer names
- paths to configured Slicer executables
- automatic-launch settings
- countdown duration
- paths to recently opened STL or 3MF files

This information is used locally by SlicerLauncher.

### Network communication

SlicerLauncher 1.1.0 does not perform an automatic update check and does not upload model files, settings, usage information, or telemetry.

The About window contains links to the official 3dprintkings website and the public GitHub source repository. Network access occurs only if the user chooses to open one of those links.

Microsoft Store installation and updates are handled by Windows / Microsoft Store, subject to Microsoft's own privacy practices.

### Analytics, advertising, and tracking

SlicerLauncher does not contain:

- analytics SDKs
- advertising SDKs
- behavioural tracking
- usage telemetry
- user accounts
- cloud storage of model files

### Third-party applications

When a user chooses a Slicer, SlicerLauncher starts the locally configured executable and can pass the selected model-file path to it. From that point onward, the third-party application's own privacy practices apply.
