# SlicerLauncher 1.1.0

SlicerLauncher 1.1.0 focuses on a simpler Slicer-management workflow and UI refinements.

## Highlights

- New **Manage Slicers** screen
- Drag-and-drop ordering, with the first Slicer acting as default
- Optional automatic launch of the default Slicer after a configurable countdown
- Duplicate Slicer names and executable paths are prevented
- Flashforge Flash Studio detection
- Improved Fusion 360 instructions
- Updated application branding and icons
- Numerous layout and usability refinements
